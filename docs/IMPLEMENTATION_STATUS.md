## 📝 使用說明

### 啟動系統

```bash
# 啟動所有服務
docker-compose up -d

# 查看服務狀態
docker-compose ps

# 查看日誌
docker-compose logs -f
```

### 訪問介面

- **前端**: http://localhost:3000
- **後端 API**: http://localhost:8000
- **API 文檔**: http://localhost:8000/docs

### 創建搜尋任務

1. 訪問前端介面
2. 點擊 "新增任務"
3. 輸入關鍵字和城市
4. 選擇目標平台
5. 設定最大結果數
6. 點擊 "開始搜尋"

### 查看結果

1. 前往 "資料庫" 頁面
2. 使用篩選器查找特定結果
3. 查看聯絡資訊和品質分數
4. 匯出為 Excel 檔案
